# Koch Fractal Explorer

**An interactive Koch snowflake and fractal curve visualiser built with Python Turtle.** Explore recursive geometry, experiment with iteration depth, change colours and rendering settings, inspect live mathematical metrics, and export resolution-independent SVG artwork—all without third-party Python packages.

![Koch snowflake at iteration 4](koch_snowflake_preview.png)

> The preview above shows the level-4 snowflake generated by the geometry engine. If the image is not displayed on GitHub, place `koch_snowflake_preview.png` next to this README or remove the image line.

## Features

- **Three fractal modes:** classic outward Koch snowflake, open Koch curve, and inward-bump snowflake.
- **Adjustable detail:** iteration levels **0–7**, with keyboard controls for exploring complexity.
- **Interactive Turtle visualisation:** fit-to-window display, zoom, 15° rotation steps, redraw, and help overlay.
- **Four colour palettes:** `ice`, `aurora`, `sunset`, and `mono`.
- **Display options:** light/dark background and optional fill for closed shapes.
- **Progressive drawing:** fast batched rendering or a slower animation, with pause/resume and progress information.
- **Live mathematics:** segment count and total boundary length; enclosed area for the classic snowflake.
- **SVG export:** save vector artwork from the GUI or generate files headlessly from the command line.
- **Built-in regression tests:** check analytical geometry, closed/open paths, perimeter, area, legacy Turtle path equivalence, and SVG output.
- **Standard-library-only core:** no NumPy, Pillow, Matplotlib, or `pip install` required.

## Quick start

### Requirements

- **Python 3.10+ recommended.**
- **Tkinter/Turtle** for the interactive window (usually included in standard Python installations).
- No external Python dependencies.

Download `koch_fractal_explorer.py` and launch it from a terminal in the same directory:

```bash
python koch_fractal_explorer.py
```

On systems where Python is invoked as `python3`, use:

```bash
python3 koch_fractal_explorer.py
```

The default launch draws the **classic snowflake at iteration 4** with side length **300**, the **ice** palette, a dark background, and fast rendering.

### Export without a graphical display

Tkinter is **not needed** for the headless SVG exporter or regression tests:

```bash
python koch_fractal_explorer.py --no-gui --export snowflake.svg
```

`--no-gui` must be combined with `--export` unless you are running `--self-test`.

## Keyboard controls

Click the Turtle window if keyboard input does not respond.

| Key | Action |
| --- | --- |
| `↑` / `↓` | Increase / decrease iteration level (0–7) |
| `←` / `→` | Cycle between snowflake, curve, and inward modes |
| `C` | Cycle through the four colour palettes |
| `F` | Toggle fill (closed shapes only) |
| `B` | Toggle dark / light background |
| `A` | Toggle fast / slow progressive drawing |
| `Space` | Pause / resume an unfinished drawing |
| `+` / `=` | Zoom in |
| `-` | Zoom out |
| `Q` / `E` | Rotate by −15° / +15° |
| `S` | Open the Save SVG dialog |
| `R` | Redraw the current fractal |
| `H` | Show / hide the help overlay |

The GUI limits zoom to **0.25×–4×**. Changing a mode, colour, level, or display setting restarts the current drawing.

## Command-line interface

```text
python koch_fractal_explorer.py [OPTIONS]
```

| Option | Description | Default |
| --- | --- | --- |
| `--level N` | Koch subdivision level, from `0` to `7` | `4` |
| `--length VALUE` | Finite, positive starting side length | `300.0` |
| `--mode MODE` | `snowflake`, `curve`, or `inward` | `snowflake` |
| `--palette NAME` | `ice`, `aurora`, `sunset`, or `mono` | `ice` |
| `--animate` | Start with slower progressive drawing | Fast mode |
| `--fill` | Fill closed shapes | Off |
| `--light` | Use a light background | Dark |
| `--export PATH` | Write a vector SVG file; still launches GUI unless `--no-gui` is specified | None |
| `--no-gui` | Export without opening a Turtle window | Off |
| `--self-test` | Execute built-in regression tests and exit | Off |
| `-h`, `--help` | Print built-in help | — |

## The mathematics

The Koch construction replaces every straight segment with four segments, each one-third as long. At each new iteration, the middle third is replaced by two sides forming a 60° triangular peak.

For an initial side length **L** and iteration number **n**:

| Metric | Formula |
| --- | --- |
| Segments in one Koch curve | `4^n` |
| Segments in the snowflake | `3 × 4^n` |
| Length of each segment | `L / 3^n` |
| Total snowflake perimeter | `3L × (4/3)^n` |
| Fractal dimension of the limiting curve | `log(4) / log(3) ≈ 1.26186` |

The classic snowflake's area at iteration **n** is:

```text
A₀ = (√3 / 4) × L²
Aₙ = A₀ × [8 − 3 × (4/9)^n] / 5
```

At the default **L = 300**, **n = 4**:

| Quantity | Value |
| --- | ---: |
| Segments | **768** |
| Individual segment length | **3.703704 units** |
| Total perimeter | **2,844.444444 units** |
| Enclosed area | **61,441.473092 square units** |

> **About the fractal dimension:** the dimension above describes the ideal infinitely refined Koch curve. A rendered level-7 curve is still a finite polygonal approximation. The program reports the analytic area only for the standard outward snowflake; it does not invent area values for the open curve or inward variant.

## How it works

The source keeps the original recursive `snowflake(lengthSide, levels)` Turtle-compatible function. Its interactive renderer instead uses an **iterative geometric subdivision** method:

1. Start with one line segment (`curve`) or a closed equilateral triangle (`snowflake` / `inward`).
2. Replace every segment with four segments using points at one-third and two-thirds of its length.
3. Rotate the middle-third vector by **+60°** for the standard modes or **−60°** for the inward mode.
4. Repeat for the selected iteration level to build a list of complex-number vertices.
5. Centre, optionally rotate, scale and draw the geometry in batches while updating an on-screen status display.
6. Use the generated vertices to construct chunked SVG paths on export.

### Important functions and classes

| Component | Role |
| --- | --- |
| `snowflake(lengthSide, levels)` | Preserves the original recursive Turtle Koch curve function |
| `koch_points(length, level, mode)` | Builds vertices with iterative subdivision |
| `transformed(points, angle, zoom)` | Centres, rotates and scales a point list |
| `fractal_metrics(length, level, mode)` | Calculates analytic segment counts, lengths and standard snowflake area |
| `palette_color(palette, t)` | Interpolates colours along the path |
| `svg_document(...)` / `export_svg(...)` | Builds and saves SVG artwork |
| `KochExplorer` | Controls the Turtle GUI, hotkeys and progressive rendering |
| `run_self_tests()` | Checks geometry and regression invariants |

### Complexity and performance

A Koch curve has **4^n** segments; each closed snowflake mode has **3 × 4^n**. Consequently, both vertex storage and drawing work grow exponentially with iteration depth. Geometry construction is **O(4^n)** in time and memory for a single curve, or **O(3 × 4^n)** for a full snowflake.

| Level | Curve segments | Snowflake / inward segments |
| ---: | ---: | ---: |
| 0 | 1 | 3 |
| 1 | 4 | 12 |
| 2 | 16 | 48 |
| 3 | 64 | 192 |
| 4 | 256 | 768 |
| 5 | 1,024 | 3,072 |
| 6 | 4,096 | 12,288 |
| 7 | 16,384 | 49,152 |

The fast renderer draws many segments per screen update; slow animation draws smaller batches. Fast mode is **not** constant-time, and levels 6–7 may render slowly on some systems. SVG output can also be large at high detail.

## Testing and validation

Run:

```bash
python koch_fractal_explorer.py --self-test
```

The test suite verifies:

- Vertex and segment counts for all three modes at levels 0–5.
- Open-versus-closed path properties.
- Expected length of every subdivided segment and the total boundary length.
- The classic snowflake's area against a polygon shoelace calculation.
- Exact geometric equivalence (within floating-point tolerance) to the original Turtle turn instructions at levels 0–4.
- Level-7 snowflake vertex count and basic SVG generation.

These checks validate the geometry and export generation logic; they are **not** cross-platform GUI automation tests.

## SVG exports

SVG is a vector format: the geometry remains sharp when resized in a browser or vector editor. This application exports to a **1,200 × 900** SVG canvas by default and automatically fits the geometry inside it.

- The **GUI Save** action includes the current fractal mode, level, palette, fill, background and rotation.
- **Command-line exports** use options provided at launch.
- The SVG export does **not** reproduce the GUI's interactive zoom setting; it scales artwork to fit the SVG canvas.
- Closed-shape SVG fill uses partial opacity, so it may look different from the opaque Turtle fill.

## Troubleshooting

**No graphical window / `TclError`** — Run the application in a desktop session with GUI support or use `--no-gui --export output.svg`. On some Debian/Ubuntu systems, Tkinter may need to be installed separately (`sudo apt install python3-tk`).

**Keyboard controls do not work** — Click inside the Turtle window to restore keyboard focus.

**Drawing is slow or unresponsive** — Try a smaller iteration level, toggle fast rendering with `A`, or generate the image using headless SVG export.

**`--no-gui requires --export`** — Provide an output path, for example `--no-gui --export fractal.svg`.

**The preview image is missing on GitHub** — Add the referenced PNG alongside `README.md`, or remove the preview image reference.
